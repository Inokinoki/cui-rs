# Licenses of what `cui-rs` embeds

The binding is MIT (the repository's `LICENSE`). One part of it derives
from third-party work:

- `LICENSE-Lucide.txt` — the Lucide icon glyphs (ISC, and MIT for the icons
  the file lists). The `ICON_*` constants in `src/icons.rs` are these
  glyphs' UTF-8 strings, generated from CUI's `cui_icons.h`.

`vendor.sh` copies the text unchanged from the pinned upstream release.
